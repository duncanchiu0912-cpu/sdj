# 發票存摺

以繁體中文打造的輕量發票紀錄工具，可在瀏覽器中新增、編輯、刪除與搜尋發票，依月份和消費類別篩選，並檢視本月及累計支出。

## 使用方式

直接用瀏覽器開啟 `index.html` 即可，無需安裝套件或啟動伺服器。

## 功能

- 儲存發票號碼、日期、店家、金額、類別、發票類型與備註
- 本月消費與累計金額摘要
- 搜尋發票、店家及備註，依月份或類別篩選
- 匯出 JSON 備份，或從備份匯入資料
- 自適應手機與桌面版面

## 資料說明

目前資料儲存在瀏覽器的 `localStorage`，只適合個人裝置上的本機使用；沒有連線雲端、登入帳號或串接財政部電子發票平台。清除瀏覽器資料可能會刪除紀錄，建議定期匯出備份。
